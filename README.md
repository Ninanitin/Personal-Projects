# Personal Projects

This repository is a **collection of personal projects**.  
Each project is organized in its own branch.

## How to Explore
- Switch between branches to view different projects.
- The `main` branch contains the base setup and repository information.
- Example: to see the `discussion_project`, switch to the branch named `discussion_project`.

## Notes
- New projects will be added as separate branches.
- Each branch contains its own project files and documentation.
